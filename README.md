# TaskManagement

## Problem

Managing daily tasks manually can make it difficult to organize work, track progress, and keep tasks up to date across different devices.

## Solution

TaskManagement provides a centralized application for creating, managing, and tracking tasks. The system allows users to organize their work, update task information, and manage tasks through a mobile-friendly interface.

The application is built with a separate **Flutter frontend** and **ASP.NET Core Web API backend**, making the system easier to maintain and extend.

## Project Description

**TaskManagement** is a task management application developed to help users organize and track their daily work.

### Main Features

* Create, update, and delete tasks.
* View and manage task information.
* Track task progress and status.
* User authentication and authorization.
* Connect the mobile application with a RESTful API.
* Local data storage for improved application experience.
